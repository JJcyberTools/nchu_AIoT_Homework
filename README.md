# NCHU AIoT 作業 - 個人專屬時間儀表板 (Chrono Identity)

一個結合個人身份稱呼、即時高精度時鐘、動態問候與現代毛玻璃（Glassmorphism）美學的時間儀表板網頁。

## 🌟 功能特色

1. **個人專屬姓名展示與自訂**：
   - 支援線上自訂姓名與暱稱，點擊即可修改。
   - 姓名自動儲存於瀏覽器 `localStorage`，重新整理也不會消失。
   - 隨時段自動切換問候語（清晨、早安、午安、午後、晚安、深夜）與對應圖示。

2. **精準動態時鐘（雙模式切換）**：
   - **數位模式**：以清晰大字顯示時、分、秒，帶動態呼吸冒號。
   - **指針模式**：高雅指針時鐘，時、分、秒針即時平滑運轉。
   - **12H / 24H 制**：支援一鍵切換 24 小時制或 12 小時制（含 AM/PM 提示）。

3. **完整日期與時區資訊**：
   - 顯示西元年、月、日與繁體中文星期。
   - 自動偵測並顯示本地時區（例如 GMT+8 台北時間）。

4. **數據概況小工具**：
   - **今日已度過進度條**：動態計算今日已度過的百分比與剩餘小時數。
   - **當年度統計**：顯示當年度週次以及距離新年的倒數天數。
   - **世界時區一覽**：即時換算東京、倫敦、紐約、舊金山時間。

5. **4 款現代主題切換**：
   - 極光魅影 (Aurora - 預設)
   - 電馭霓虹 (Cyberpunk)
   - 暮霞煦陽 (Sunset)
   - 曜石深邃 (Midnight)

## 📁 檔案結構

```text
├── index.html        # 網頁主要結構與語意標籤
├── style.css         # 現代毛玻璃設計系統與主題樣式
├── app.js            # 即時時鐘計算、姓名自訂與互動邏輯
└── README.md         # 專案說明文件
```

## 🚀 執行方式

1. **直接開啟**：在檔案總管中雙擊 `index.html` 即可在瀏覽器開啟。
2. **透過 HTTP 伺服器**：
   ```bash
   # Python
   python -m http.server 8080
   
   # 或使用 Node.js
   npx http-server -p 8080
   ```
   瀏覽器造訪 `http://localhost:8080` 即可預覽。
